# Placement Management System 🚀

A full-stack web application designed to streamline campus recruitment drives with automated eligibility screening and JWT-based role management.

## 🌟 Key Features
- **Role-Based Access Control (RBAC):** Distinct access levels for TPOs, Companies, and Students using JWT authentication.
- **Automated Eligibility Engine:** Instant filtering of candidates based on CGPA and branch criteria.
- **RESTful APIs:** Scalable Node.js & Express backend architecture.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** React.js, HTML5, CSS3
- **Authentication:** JSON Web Tokens (JWT)
- **Tools:** Git, GitHub, Postman, VS Code / Cursor
